评估协议

数据与范围
AutoVOT 上游 tutorialExample/test 的全部 58 段。目标是英语承载句中的词首 /p b/；没有 /t k d ɡ/ 测试样本。说话人数与母语背景未核实。
输入不是人工答案
从 words 层选 ABOVE 前的目标词，再由 phones 层选词首塞音及后续元音。裁切起点是音素起点前 25 ms，终点是后续元音结束。人工 vot 层只用于评分，不传给检测算法。
已提供的辅助信息
这是带粗音素边界辅助的片段测试；不能等同于任意完整句子的自动识别，也不能证明麦克风实机表现。
算法与判定
当前网页 heuristic-v0.1，未根据本测试集调参。10/20 ms 是工程评估尺度；报告的“有前景”门槛为检出率 ≥90% 且全样本 ≤20 ms 比例 ≥80%，不是通用或预注册科研标准。
未验证的功能
普通话、粤语、负 VOT、自动闭塞时长、辅音身份识别与发音评分。

一键复跑与来源

安装 Python 3 与 Node.js 后，从仓库 consonantscope 目录运行：

python scripts/run-validation.py

流程自动下载固定版本数据、验证文件哈希、运行测试、生成 results.json／results.csv。GitHub Actions 在相关代码提交后自动复跑并保存报告附件；不会把原始录音提交到仓库，也不会自动改写网站报告。
