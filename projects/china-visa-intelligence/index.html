China Passport Visa Intelligence Prototype

A rule-engine prototype for PRC ordinary passport holders. It evaluates passport-only access, access unlocked by existing visas, eVisa / visa-on-arrival records, transit-only records, and visa-required destinations. The design prioritizes source traceability and manual review flags over visual polish.

Passport visa-free Existing visa unlock eVisa / VOA Transit only Visa required Unknown / insufficient data
Prototype warning: only a small starter dataset is included. Records marked “manual review” must not be treated as legal travel advice.
