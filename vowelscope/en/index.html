About this experiment

This experimental phonetics tool uses LPC to estimate formants and displays the nearest schematic reference quality, not a verified phoneme recognition. Optional anti-jitter filtering attempts to reject some consonant noise before plotting vowel positions. Language selection highlights common vowel qualities; it does not load language-specific measured F1/F2 references or speech models. All reference positions are approximate and vary by language, individual, vocal tract length and speaking conditions. Actual tongue shape cannot be uniquely inferred from these measures. Start with sustained /i/, /a/ and /u/ instead of full words.

Phonetics references: International Phonetic Association · EdUHK Cantonese phonology · Spanish vowels (University of Florida) · British diphthong change.
