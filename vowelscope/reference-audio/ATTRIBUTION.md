# IPA teaching audio attribution

These 28 MP3 teaching derivatives are licensed under **Creative Commons

https://creativecommons.org/licenses/by-sa/3.0/

The source distribution credits the audio collection to **Peter Isotalo,
User:Erutoon, User:TFighterPilot and User:Adamsa123**. These are collective
credits supplied by the distributor, not a claim that each file has all four
performers. We retain the supplied credits without inventing per-file authors.

Source collection: https://github.com/serverhiccups/ipa-chart
Pinned revision: fc6270c08a8aed6141cbe04595db8801ba767b49
Audio-specific permission/credits: see UPSTREAM_README.md and its CC BY-SA 3.0
audio statement. The site's separate CC BY-SA 4.0 license is not substituted
for the recording license. The README's older assets/sounds path corresponds
to the collection now served under public/sounds in the pinned tree.

Changes by VowelScope: Ogg Vorbis recordings converted to mono 44.1-kHz MP3
(libmp3lame, 128 kbit/s), with title/license metadata. No deliberate pitch,
speed, formant or vowel-identity transformation. Lossy conversion changes
samples and can introduce codec padding. Derivatives retain CC BY-SA 3.0.

The original OGGs remain in an external cache; no independent validation
recordings or private reference data are included here. The packaged MP3s
are deliberately redistributable public teaching assets.

The companion upstream-symbol-data.json is an unchanged mapping excerpt
file from the source project's CC BY-SA 4.0 site code/data. Its original
site license: https://creativecommons.org/licenses/by-sa/4.0/
The mapping is retained for provenance verification, not executed by the app.
The recording-name lookup in reference-player.js is adapted from that catalog
and retains CC BY-SA 4.0; its order and local MP3 URLs were changed by VowelScope.

Each displayed symbol's original file/title, pinned source URL, source hash
and derivative hash is listed in ../reference-audio-sources.json. Each
example is a community IPA illustration, not an official institutional
certification or a unique language/accent pronunciation standard.
